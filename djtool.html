DJ Tool

DJ Tool is a music download and playlist management tool that is optimized for the the production of both live and pre-recorded radio programs. It's iTunes/VLC like interface provides the following features:
  • Song lookup by artist and song title using fuzzy search, e.g. Kinks ; Lola
  • Fast download of tracks in broadcast ready format
  • Automatic playback start/stop for mic breaks and pauses
  • Drag and drop track reordering
  • Show export as an MP3 file
  • Automatic spin submission to playlist (live shows)
  • Convenient track editing
  • Accept file drops from external sources
  • Song check for explicit lyrics
  • Album lookup
  • Interface to USB Codecs
  • Zookeeper playlist generation

Live Show Quickstart

The following steps describe how to use DJTool for live shows. Note that songs can be downloaded while the show is in progress.
  • Use Zookeeper to create an empty playlist for your show
  • Start app using Mac's Spotlight launcher, e.g.Cmd-<SPACE> and enter DJTool
  • Click Live Show box and enter show name and click OK
  • Download songs by entering <ARTIST_NAME> ; <SONG_TITLE> into the Song field and clicking Fetch
  • Start playback by double clicking the 1st song in the track list
  • Use Edit->Insert Mic-Break (or Pause) and drag it below the last song in set
  • Download tracks for next set
  • Playback will stop when the MIC_BREAK track is hit
  • Do track readback
  • If app is out of focus, click on it to reactivate
  • Resume playback by tapping the space bar
  • Drag MIC_BREAK to the next readback point
  • Upon show completion exit app and confirm playlist deletion

    • Quickstart Hints

  • If song search fails, use direct entry of the YouTube video URL
  • Entering <SPACE> toggles between play and pause modes
  • Songs can be downloaded during playback
  • Fast switch to another track by double clicking it
  • Each track spin will be timestamped and appended to your show playlist
  • Track information can be edited by Shift-Clicking the song row
  • Mic-Break stops playback and inserts a break line in your playlist
  • Pause stops playback and does NOT add a playlist break line

    • Adding Songs

    Songs can be added to the playlist through the following actions:
    • Entering <ARTIST_NAME> ; <SONG_TITLE> into the URL input field
    • Entering YouTube video URL into the URL input field
    • Dragging a local audio file into DJTool
    Songs are downloaded from YouTube by entering the URL of a video page or by entering the song info as <ARTIST_NAME> ; <SONG_TITLE> into the URL input field and clicking Fetch or entering <ENTER>. After short delay, a broadcast ready (no ads and leading/trailing silence trimmed to 2 seconds) copy of the track will be added to your local drive as a opus file and appended to the playlist. Note that it is not necessary to enter full artist and title names. Entering enough of it to identify the song is sufficient, e.g "cliff; harder" would download Jimmy Cliff's great song. If the song search returns multiple results, then a song a choice picker will be presented. In order to accommodate copy/pasting of artist/ssong from outside playlists, the URL input field also accepts TAB and - as field separaters. The album will be added to the playlist when downloading with the artist/title input format but not for downloads using the video URL. For the latter, the album titles can be found with the Find Albums feature. Local files can be added to your playlist by using the Finder application to drag the files into the list display area of the tool.

    Importing Local Audio Files

    The import audio function imports external song files into the playlist. It activates a file / folder selection dialog. If a folder is selected then all audio files under it will be imported. Alternatively, individual audio files can be selected for import. Note that the external files will not be deleted upon playlist deletion, e.g. deletion removes only downloaded files.

    Editing Track Information

    Playlist track info can be modified selecting a track by clicking on it and then chosing the Edit->Edit Track function (or by doing a Shift-Click on directly the target track) and updating the track information in the Edit Track pop dialog. If the FCC status is changed from DIRTY to CLEAN, e.g. after removing any offending language, then '(CLEAN)' will be appended to the track title as a reminder of the change. Note that the the edit dialog provides a link to the song lyrics page and a summary of any explitives, e.g. shit 3x.

    Playlist Load and Save/Update

    Playlists can be import & exported using the File->Load and File->Save/Update functions. Playlist save/update writes the current playlist state to the following files:
    • <SHOW_NAME>.json - DJTool playlist
    • <SHOW_NAME>_zookeeper.csv - Zookeeper playlist import file
    The djtool playlist allows you to save the current show state and restore it later using the Load Playlist command. The 'zookeeper' version allows you to import your playlist into Zookeeper using its 'Import Playlist' option and the 'm3u' version is can be used with tools like VLC. Unlike the save operation, which prompts for a new playlist name, the update operation will overwrite the previously loaded playlist file with your latest changes. The name of the current playlist is displayed whenever the app is stopped.

    Explicit Language Checking

    Upon song download, DJTool attempts to find the song lyrics and if found checks for potential FCC violations by looking for explitives and displaying a green, yellow or red icon (CLEAN, DIRTY, and NOT_FOUND) in the song row. If the lyrics cannot be found it may be be that the artist name of song title are misspelled. In this case you can rerun the check by correcting the typos using the track edit dialog and setting the FCC status to '-' and then clicking File->FCC Check in order to rescan all songs with a '-' FCC status. Lyrics can also be checked by pasting them into the 'Check Lyrics' textbox in the Edit track dialog and clicking the Check Lyrics button. By default the textbox is populated with the track artist and title so that the lyrics can be quickly located by entering the info into the song lookup field in a site like Shazam.com. The File->Export MP3 function provides an option to export only the NOT_FOUND tracks for easy sound checking and the File->FCC Unknown Clear can be used to change all NOT_FOUND tracks to CLEAN status.

    Live Show

    The Live Show option enables automatic submission of track spins to Zookeeper as they are played. The procedure for using this feature is as follows:
    • Using Zookeeper, create an empty playlist for your show
    • Click the Live Show check box and enter show title
    Note that the show info entered into DJTool must match the playlist that you created in Zookeeper. Upon saving a confirmation will be dislayed if a corresponding Zookeeper playlist was ffound.

    User Configuration

    This function activates the configuration dialog for entering show your show title and start time. Start time should be set when creating prerecorded shows as this is the show start time that is used to timestamp your Zookeeper playlists. Start time should be set to None (default) for live shows. Note that the display time column will show that song length for live shows and the song start time for prerecorded shows.

    Mic-Break and Pause Tracks

    These tracks are used in live shows to automatically pause playback in preparation for a mic break or for playing a song from an external source like a CD. Once paused, the playback can be continued by tapping the space key. Pausing with MIC-BREAK will add mic-break entry to your playlist, while PAUSE simply pauses playback for cases in which the DJ wants to manually enter the next track into Zookeeper.

    Readback Files

    If a prerecorded show contains DJ voice work, these files should be named READBACK_<BREAK_NUMBER>, e.g. READBACK_1, as this is a trigger to DJTool to emit voice break lines to Zookeeper when played and to include timestamps in the Zookeeper CSV file. If this feature is not desired then the voice files can be arbitrarily named.

    Zookeeper Playlist Generation

    Upon playlist saves, DJTool creates a Zookeeper specific CSV file that can be used to import the show tracks using ZK's Import function. These files can imported by clicking the Import link on the Zookeeper homepage and following the directions for CSV file import.

    MP3 Export (File->Export MP3)

    This function generates an MP3 representation of the entire program that is suitable for show upload. Because this operation requires converting OPUS files to MP3 format, the process takes approximately 5 minutes for a 1 hour show.

    Output Channel Picker

    This picker selects the output device used when playing tracks. The output can be directed to the board's Aux Codec input by connecting it to your laptop and selecting using this control.

    Function Shortcuts

    The following keyboard shortcuts can be used to invoke common operations:
    • <SPACE> - toggles between play and pause modes
    • <DELETE> - deletes the selected playlist entries
    • <SHIFT-CLICK> - invokes track editor for the target track
    • <DOUBLE-CLICK> - starts playback on the target file
    • <ENTER> - initiates song download (when entered into the URL input field
    • <DRAG_DROP> - imports external files that are dragged from 'finder' tools
    • <CLICK-DRAG> - relocates song's position within the playlist
    All other DJTool functions are invoked via the application menu bar
